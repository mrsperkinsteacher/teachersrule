Gamify cheat sheet

Eight ways to get every student talking in HSIE. Each one shows the prep time and what to have ready before you open it. Pick one, run it in the time shown, and swap in today's topic.

Places in Ten GAME
0 min prep5 to 8 min

You need: nothing. Optional: a list of today's key terms or places on the board.

Show how to run itHide

Run it

  1. Pairs. One student secretly picks a place, term or case study from the lesson and writes it down so it cannot change.
  2. The partner has ten yes or no questions to find it, counting out loud.
  3. Swap roles.
  4. Debrief: which question narrowed it down the most?

Keep it moving

  • "Is it a place or an idea?" is a strong first question. Say so.
  • No naming a guess before question six, so students ask about features first.

Try it in Interconnections and Trade: globalisation, undersea cable, container tracking, digital divide, NBN, or a country linked by trade.

Adapted from "Towns in Ten" in Games and Stories by Paula Owens, Digimap for Schools (EDINA). The original is a primary map game.

Map it from memory GAME
0 min prep8 to 10 min

You need: blank paper and two pen colours (a pencil and a coloured pencil works).

Show how to run itHide

Run it

  1. Books closed. Students draw today's topic as a concept map from memory: the big idea in the middle, branches around it, and a few words on each link.
  2. Four minutes, silent.
  3. Swap with a partner. Add anything missing in the second colour, or check against notes.
  4. Each student counts what they missed. That count is their next revision target.

Try it in Interconnections and Trade: "globalisation" in the middle, with branches for trade, travel, communication, culture and risks.

Concept mapping from memory is a review activity in Mark Enser, "Applying Rosenshine to the geography classroom", Chartered College of Teaching.

Talking Point GAME
2 min prep6 to 10 min

You need: one map, photo or graph on the board, a timer, and a mini whiteboard or paper for each group.

Show how to run itHide

Run it

  1. Show the image. Groups of three or four, one scribe and one speaker.
  2. Two to three minutes to list as many facts as possible. Each fact must be something you can point to.
  3. Speakers read out their lists. A fact scores a point only if no other group has it, so groups cross out duplicates as they hear them.
  4. The winning group explains its best fact with evidence from the image.

Keep it moving

  • Ask for "I can see ... so ..." so facts turn into reasons.

Try it in Interconnections and Trade: a submarine cable map, the NBN sector graph, or a photo of a port or airport.

Adapted from "Talking Point" in Games and Stories by Paula Owens, Digimap for Schools (EDINA). The original is a primary map game.

Paired argument TALK
2 min prep8 to 10 min

You need: a decision scenario plus a map or image on the board, and sentence starters written up.

Show how to run itHide

Run it

  1. Show the scenario and the map. Students pair up as A and B.
  2. Everyone decides alone for one minute.
  3. A defends their decision for one minute using evidence from the map. B tests it: "How do you know?" "What if ...?"
  4. Swap with a new scenario, or the same one from the other side.
  5. B reports back A's strongest argument to the class.

Try it in Interconnections and Trade: where should a new undersea cable come ashore in Australia? Where should a community internet hub go?

The idea comes from Mark Enser, "Applying Rosenshine to the geography classroom", Chartered College of Teaching: pupils defend a map-based decision to a partner who tests the reasoning. The steps above are suggested.

Whiteboards and names TALK
2 min prep1 to 2 min per question

You need: mini whiteboards, markers and erasers (or paper in plastic sleeves), and name sticks or a random name picker.

Show how to run itHide

Run it

  1. Ask the question. Ten seconds of silent thinking.
  2. "Three, two, one, show me." Every board goes up at once.
  3. Scan the room. Draw a name and ask that student to explain their answer.
  4. Draw a second name: "Do you agree or disagree, and why?"

No boards?

  • Use paper held up, or a thumbs scale. The point is that everyone answers at once.

Try it in Interconnections and Trade: "What carries about 99% of international data?" or "Is this an example of trade in goods or services?"

Random name selection and mini whiteboards are described in Mark Enser, "Applying Rosenshine to the geography classroom", Chartered College of Teaching.

Post-it on the map TALK
3 min prep8 to 10 min

You need: a map, Venn diagram or continuum on the board or an A3 sheet, plus a sticky note and pen for each student.

Show how to run itHide

Prep (about 3 minutes)

  • Draw a line on the board with the two ends labelled, or print a map. Collect the sticky notes.
  • No sticky notes? Torn paper and blu-tack, or drag text boxes on a shared slide.

Run it

  1. Everyone writes one place or idea on a sticky note and places it on the map or line.
  2. Choose three notes. Ask "Why there?" and let the author explain.
  3. Anyone may move their own note after hearing the others.
  4. Finish with the biggest cluster or the biggest outlier. Why?

Try it in Interconnections and Trade: a line from "least connected" to "most connected" for a city, a regional town, a remote community and another country.

Post-it notes on maps, Venn diagrams or continua are described in Mark Enser, "Applying Rosenshine to the geography classroom", Chartered College of Teaching.

Search and destroy GAME
10 min prep10 to 12 min

You need: a short sample answer with 3 to 5 planted mistakes (one per pair, printed or on the board), an answer key for you, and pens.

Show how to run itHide

Prep (about 10 minutes, once)

  • Write a short answer to a real question from your lesson. Plant three to five common mistakes: a wrong fact, a claim with no evidence, a missing key term, a number that does not add up.
  • Keep a separate answer key. Print one copy per pair, or put it on the slide.
  • Short on time? Ask Claude to draft the answer and key from your lesson notes, then read it yourself before class.

Run it

  1. Pairs get the answer. Hunt for the mistakes and mark each one.
  2. Write the fix next to each mistake.
  3. Reveal the key. One point for each mistake found and fixed.
  4. Ask: which mistake would you be most likely to make yourself?

Try it in Interconnections and Trade: a sector graph description where the angles do not add to 360 and the title is missing, or a paragraph about the digital divide with an unsupported claim.

"Search and destroy" is from Mark Enser, "Applying Rosenshine to the geography classroom", Chartered College of Teaching: pupils find and correct deliberately flawed common errors in a sample answer.

Map jigsaw GAME
10 min prep10 to 15 min

You need: a printed map for each group (A3 is best), scissors, and a zip bag or envelope for each group. Laminate to reuse.

Show how to run itHide

Prep (about 10 minutes for a class set, reusable)

  • Print one map per group. Cut each into six to nine pieces along irregular lines.
  • Bag each set. Keep one complete copy on the board as the answer.
  • Laminated sets last for years and can be used for any lesson with a map.

Run it

  1. Hand out the pieces so each student in the group holds two or three.
  2. No showing the pieces. Describe your piece to the group, using the names and features on it.
  3. The group builds the map from the descriptions.
  4. Check against the answer. Which description helped most?

Try it in Interconnections and Trade: a world map of shipping routes or submarine cables, or a map of Australia's ports and airports.

Adapted from "Jigsaws" in Games and Stories by Paula Owens, Digimap for Schools (EDINA), where pupils describe their square to a partner before the group builds the map. The original is a primary map game.
