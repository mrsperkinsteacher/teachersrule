# Teachers Rule

A private page of teacher reference sheets. It is not linked from anywhere else and is marked noindex, so search engines are asked to skip it. Anyone with the link can still open it.

## Add a new tab
Open `index.html` and look for the comment "TO ADD A NEW TAB". Copy the `<button class="tab">` line and the `<section class="panel">` block, change the name in both, and put your content inside the section.

Each tab has its own address, for example `/#gamify`.
